# Homebrew tap of Pasadizo

This tap has the Homebrew cask of [Pasadizo](https://github.com/pasadizo-net/pasadizo), a proxy platform derived from sing-box. The release workflow of Pasadizo writes `Casks/pasadizo.rb` on each release; do not edit it by hand.

```sh
brew install --cask pasadizo-net/tap/pasadizo
```

The cask works on macOS and Linux. Pasadizo is not affiliated with sing-box or its authors.
